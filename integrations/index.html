Frequently Asked Questions

What integrations does Traffic Torch offer?
Three families. Browser extensions for Chrome, Firefox and Microsoft Edge. CMS and design plugins for WordPress, Figma and Framer. Developer tools including a VS Code extension, a GitHub Action and a REST Developer API. All free, all sharing the same audit engine as the OFUX dashboard.
Are the Traffic Torch integrations free?
Yes. Every integration is free to install and use. The Free tier gives you 3 audits per day. The same account unlocks Pro (25/day) or Enterprise (300/day) quotas across all integrations, plus saved history and cross-device sync.
Which integration should I start with?
If you audit pages while browsing, start with the browser extension for your browser. If you publish on WordPress or design in Figma or Framer, start with the plugin for your platform. If you want audits inside your editor, CI pipeline or your own apps, start with the developer tools.
Do all the integrations use the same audit engine?
Yes. The browser extensions, the WordPress, Figma and Framer plugins, the VS Code extension, the GitHub Action and the Developer API all run the same Traffic Torch audit engine that powers the OFUX dashboard. You get the same scores, the same signals and the same fix recommendations, wherever you trigger an audit.
Do the integrations send my data to a server?
No. Browser extensions, the VS Code extension and the WordPress plugin analyse content locally. Figma and Framer plugins analyse the frames and URLs you point them at. The Developer API returns results to your own infrastructure. Optional features such as saved audit history only touch the server after you log in.
Do I need a Traffic Torch account to use the integrations?
No. Every integration works without an account. Signing in is optional and unlocks higher daily quotas, saved audit history and cross-device sync. The same account works across every Traffic Torch tool, plugin and extension.
Is there an integration for Shopify, Wix or Squarespace?
Not yet. Shopify, Wix and Squarespace are on the roadmap. In the meantime, you can audit any published Shopify, Wix or Squarespace page with the browser extensions for Chrome, Firefox and Edge, or programmatically via the Developer API.
Where can I find the full API documentation?
Full endpoint reference, authentication details, error codes, rate limits, code samples in cURL, JavaScript, Python and PHP, webhook payload schema and changelog are available at traffictorch.net/integrations/developer/api/.
