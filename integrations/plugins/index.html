Frequently Asked Questions

Are the Traffic Torch plugins free?
Yes. The WordPress, Figma and Framer plugins are all 100% free. The same Traffic Torch account unlocks Pro (25 audits/day) or Enterprise (300/day) quotas across every integration, including the browser extensions and the Developer API.
Which platforms does Traffic Torch have plugins for?
Three: WordPress (posts, pages and products inside the WordPress admin), Figma (design files before handoff), and Framer (published sites from inside the Framer editor). Together they cover publishing, design and modern site builders.
Do the plugins send my content to a server?
No. The WordPress plugin performs analysis on your own WordPress server using the Traffic Torch audit engine. The Figma and Framer plugins analyse the rendered frames and published URLs. None of them stream your content to a third-party analytics service.
What can the WordPress plugin audit?
Posts, pages, products and any public custom post type. It checks on-page SEO, headings, internal links, schema markup, readability, image alt text, mobile readiness and AI-search answerability — and surfaces prioritised fixes inside the WordPress editor.
What does the Figma plugin actually check?
The Figma plugin audits your design frames for SEO and UX fundamentals before handoff: heading hierarchy, text contrast, tap-target size, mobile layout, link labels and content intent. It catches accessibility and SEO problems while they're still cheap to fix — in design, not in code.
How does the Framer plugin work?
Install it from the Framer marketplace, open it inside a Framer project, and it auto-detects your published site URL. From there you can launch any of the 14 Traffic Torch SEO, UX and AI-search tools in one click — no manual URL entry, no context switching.
Do I need a Traffic Torch account to use the plugins?
No. All three plugins work without an account. Signing in unlocks higher daily quotas, saved audit history and cross-device sync. The same account works across every Traffic Torch tool, plugin and extension.
Is there a plugin for Shopify, Wix or Squarespace?
Not yet. Shopify, Wix and Squarespace are on the roadmap. In the meantime, you can audit any published Shopify, Wix or Squarespace page with the free browser extensions for Chrome, Firefox and Edge, or programmatically via the Developer API.
