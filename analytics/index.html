Traffic Torch, In the Open

Live Cloudflare edge data — every request, every byte, every AI crawler that hits the site. Public because analytics shouldn't be private.

What's public: request volume, unique visitors, bandwidth, top paths, top countries, status code distribution, per-crawler request counts (AI + search), plus Google Search Console aggregates.

What's never public: personal data, search query text, referrer URLs, individual visitor sessions, or IP addresses. Refresh: every 6 hours. Date range: ends yesterday for Cloudflare, 2 days ago for Search Console.

Why make this public?

Because hiding analytics is a choice, not a requirement. Sharing real numbers keeps us honest, shows what's working, and lets anyone sanity-check our claims — including how much of our traffic is AI crawlers.
