How it works — and what it can't see ▾

What the tool does: parses your log line by line, identifies every request whose User-Agent claims to be a known crawler, then verifies the source IP against the operator's published IP ranges. Only requests where both UA and IP match are marked verified. Mismatches are flagged as unverified — usually spoofed scrapers.

What you'll see per bot: total hits, verified vs unverified counts, status code breakdown (2xx / 3xx / 4xx / 5xx), the count of 401 / 403 / 429 / 503 responses (rate-limit and block indicators), first and last seen timestamps, top requested paths, and any unverified source IPs.

What this tool can't see: CDN-level blocks and rate limits that never reach your origin (Cloudflare, Fastly, Akamai) are invisible in your origin log. Cached responses served from the CDN edge also never hit origin. If you suspect CDN blocks, check your CDN provider's own analytics.

What it does not do: no reverse DNS lookups (they require per-IP server-side queries, which would break the privacy promise and add latency). UA + IP range verification catches the vast majority of spoofing attempts.

IP list freshness: operators update their ranges rarely. The tool caches the list for 24 hours. Force a refresh by clearing browser storage.

Supported bots and IP-list availability ▾

Have published IP ranges (verified matching):

  • Googlebot, Googlebot-Image, Googlebot-News — Google published ranges
  • Bingbot — Microsoft published ranges
  • Applebot — Apple published ranges
  • GPTBot, OAI-SearchBot, ChatGPT-User — OpenAI published ranges
  • Amazonbot — Amazon published ranges

UA only (no published IP ranges):

  • ClaudeBot, Claude-Web, anthropic-ai — Anthropic has not published ranges
  • PerplexityBot, Perplexity-User — Perplexity has not published ranges
  • CCBot — Common Crawl, UA-only
  • Bytespider — ByteDance, UA-only
  • DuckAssistBot, YandexBot — UA-only

For UA-only bots, hits are shown as "UA only" rather than "verified" — the tool can't confirm IP authenticity, so we don't pretend to.
